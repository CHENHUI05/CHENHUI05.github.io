## 一、强化学习到底是什么？

### 1.1 先看一个生活例子：训练小狗

你想教会小狗"坐下"。小狗一开始根本听不懂人话，它只会瞎动：站起来、转圈、叫两声……

- 当它偶然做出"坐下"这个动作时，你立刻给一块零食（**奖励**）；
- 当它做其他动作时，你不给零食，甚至说"不行"（**惩罚**）。

反复多次之后，小狗脑子里建立起了一个联系：**"听到坐下指令 → 屁股着地 → 有零食"**。于是它学会了坐下。

注意整个过程：你没有给小狗一本《坐下动作教科书》让它背诵标准答案，你只是在它每次行动后给一个"好/坏"的反馈，让它自己去试、去总结。

**强化学习就是这个机制的数学化、程序化版本**：一个智能体（Agent）在环境（Environment）中不断采取行动，根据环境返回的奖励（Reward）调整自己的行为，最终学会一套能拿到最多奖励的策略。

### 1.2 它和监督学习有什么区别？

很多人分不清机器学习里的几种学习方式，一张表说明白：

| 学习方式 | 比喻 | 数据长什么样 | 典型任务 |
|---|---|---|---|
| **监督学习** | 老师拿着标准答案批改作业 | 输入 + 正确答案（标签） | 图片分类、房价预测 |
| **无监督学习** | 给你一堆东西自己找规律归类 | 只有输入，没有答案 | 用户分群、异常检测 |
| **强化学习** | 边玩边学，做对了给糖、做错了挨打 | 一连串"行动—反馈"，没有标准答案 | 游戏 AI、机器人控制、自动驾驶决策 |

关键区别在于：**监督学习每做一道题都立刻知道标准答案；强化学习没有标准答案，它只知道自己刚才那一步拿到了多少分，要靠自己摸索"怎么做才能总分最高"。**

### 1.3 强化学习的三个"麻烦"之处

正因为没有标准答案，强化学习有几个独特的难点，后面会逐一展开：

1. **要靠试错（Trial and Error）**：没做过的动作，怎么知道好不好？只能试；
2. **奖励可能是延迟的**：下棋时，第 30 步的妙手，可能要到第 200 步赢棋才体现出来；
3. **探索与利用的矛盾**：是继续用已知的好办法，还是去试试可能更好的新路？

## 二、五个核心概念（用走迷宫讲明白）

为了讲清楚过程，我们设计一个贯穿全文的小游戏：**4×4 走迷宫**。

```
S  .  .  .
.  .  .  .
.  .  X  .
.  .  .  G
```

- `S` 是起点，`G`（Gold）是金币，`X` 是陷阱，`.` 是普通空地；
- 小人从 `S` 出发，每次只能向上、下、左、右走一格；
- 走到金币处获胜，掉进陷阱失败。

在这个场景里，强化学习的五个核心概念一一对应：

| 概念 | 英文 | 在迷宫里指什么 | 通俗理解 |
|---|---|---|---|
| **智能体** | Agent | 走迷宫的小人 | 做决策、学习的"玩家" |
| **环境** | Environment | 整个迷宫及其规则 | 智能体所处的、会对动作做出反应的世界 |
| **状态** | State | 小人当前在哪个格子 | 当下的处境（用坐标表示，如 (0, 0)） |
| **动作** | Action | 上 / 下 / 左 / 右 | 智能体能做出的选择 |
| **奖励** | Reward | 金币 +1、陷阱 −1、每走一步 −0.01 | 环境对动作的即时打分 |

还有两个高频术语，先混个脸熟：

- **回合（Episode）**：一局游戏，从起点开始到"吃到金币或掉进陷阱"结束；
- **策略（Policy）**：在每个状态下应该选哪个动作的规则，相当于智能体的"行为习惯"。**强化学习的最终目标，就是学到一个最优策略。**

你可能会问：为什么走一步要扣 0.01 分？这是故意的——它鼓励智能体**别绕弯子，尽快到达金币**。如果走路不扣分，小人在迷宫里乱逛一辈子也不着急，就学不到"最短路径"。**奖励函数的设计，是强化学习里最重要也最考验功力的环节。**

## 三、核心循环：智能体与环境如何交互

强化学习的全部过程，可以浓缩成下面这个无限循环。它是整个领域的"主心骨"，务必先建立这张图的印象：

{% mermaid %}
flowchart LR
    A["智能体 Agent"] -->|"第 t 步：执行动作 a_t"| B["环境 Environment"]
    B -->|"返回新状态 s_(t+1)"| A
    B -->|"返回奖励 r_(t+1)"| A
{% endmermaid %}

把它"翻译"成大白话，每一步都在重复三件事：

1. 智能体观察自己当前的状态 `s_t`（"我在 (0,0) 这个格子"）；
2. 智能体根据策略选择一个动作 `a_t`（"我决定向右走"）；
3. 环境发生变化，返回新状态 `s_(t+1)`（"你到了 (0,1)"）和奖励 `r_(t+1)`（"扣 0.01 分"）。

然后进入下一步，智能体在新状态下再决策、再行动……如此循环，直到回合结束。

智能体一生要经历成千上万个回合，每个回合几十上百步，**它就在这海量的"行动—反馈"中慢慢变聪明**。我们训练 AI，本质上就是让这个循环高速运转起来。

## 四、智能体的目标：不是眼前赚一笔，而是长期总收益

### 4.1 只看眼前会吃亏

假设小人眼前有两条路：

- A 路：这一步立刻能捡到 0.1 分，但再往前走是陷阱，最终 −1 分；
- B 路：前几步什么都没有，但一直走能吃到金币，最终 +1 分。

如果智能体"目光短浅"，每次都选眼前奖励最大的动作，它会毫不犹豫地走 A 路，然后反复掉坑。这叫**贪心陷阱**。

所以我们必须让智能体**追求长期总收益**，而不是一步的得失。

### 4.2 回报（Return）：把一局的奖励加起来

从第 t 步开始，到回合结束，智能体拿到的所有奖励之和，叫做**回报**，记作 `G_t`：

```
G_t = r_(t+1) + r_(t+2) + r_(t+3) + … + r_结束
```

### 4.3 折扣因子 γ：为什么未来的奖励要"打折"？

直接相加还有个问题：十年后的 100 块和今天的 100 块，价值不一样。于是我们引入一个 0 到 1 之间的数——**折扣因子 γ（gamma）**，让越遥远的奖励权重越低：

```
G_t = r_(t+1) + γ·r_(t+2) + γ²·r_(t+3) + γ³·r_(t+4) + …
```

- γ 接近 1（比如 0.99）：智能体很有"远见"，愿意为长远利益忍耐；
- γ 接近 0（比如 0.1）：智能体很"短视"，基本只在乎眼前的奖励；
- 本文取 γ = 0.9。

**举个算账的例子**：假设再走 3 步就能吃到金币，路上每步扣 0.01，金币 +1。那么站在起点看，这条路线的回报是：

```
G = (-0.01) + 0.9×(-0.01) + 0.9²×(-0.01) + 0.9³×(1.0)
  = -0.01 - 0.009 - 0.0081 + 0.729
  ≈ 0.70
```

是正的，值得走。而通往陷阱的路线回报是负的，自然会被淘汰。

## 五、Q 值：给每个"选择"打一个长期分数

### 5.1 核心直觉

智能体在每个状态下都要做选择。如果我们能提前知道：

> "在状态 s 下采取动作 a，未来（按最优方式走下去）总共能拿到多少分？"

那决策就变得异常简单——**哪个动作分高就选哪个**。

这个"长期分数"就叫做 **Q 值（Action-Value）**，记作 `Q(s, a)`。

### 5.2 Q 表长什么样

我们的迷宫有 16 个格子（状态），每个格子有 4 个动作，于是 Q 值可以组成一张 **16 行 × 4 列的 Q 表**：

| 状态 | 向上 ↑ | 向下 ↓ | 向左 ← | 向右 → |
|---|---|---|---|---|
| (0,0) | −0.05 | 0.62 | −0.05 | **0.66** |
| (0,1) | 0.05 | 0.55 | 0.10 | **0.73** |
| (0,2) | 0.20 | 0.70 | 0.20 | **0.81** |
| … | … | … | … | … |
| (3,2) | 0.60 | 0.65 | 0.70 | **0.99** |

（上面是训练后期的示意数值，不是初始值。）

在 (0,0) 这一格，"向右"的 Q 值最高，所以小人就向右走——这就是策略。**所谓"学习"，本质上就是不断修正这张表，让每个 Q 值都逼近真实的长期收益。**

### 5.3 Q 值怎么算出来？贝尔曼方程

一开始 Q 表全是 0（因为小人对世界一无所知）。那它靠什么公式更新？这就是强化学习的基石之一——**贝尔曼方程（Bellman Equation）**的 Q 版，别被名字吓到，它说的是一句大白话：

> **一个选择的长期价值 = 眼前拿到的奖励 + 折扣后的"下一站最优价值"。**

写成公式：

```
Q(s, a) = r + γ × max Q(s', a')
          │     │       └─ 下一个状态 s' 下，所有动作里最高的 Q 值
          │     └─ 折扣因子
          └─ 执行动作 a 后立刻拿到的奖励
```

直觉非常巧妙：**我不需要看到终点，我只要知道"下一步那个格子的最优价值"，就能倒推出当前格子的价值。** 就像下楼梯，每一级台阶的高度由下一级决定，一级一级地，终点的"高分"会像潮水一样倒灌回起点的所有格子。

这就是 Q-Learning 算法的核心思想，下一节我们动手实现它。

## 六、探索与利用：ε-greedy 策略

### 6.1 一个哲学问题

假设你家楼下有家面馆，你吃过 10 次，觉得能打 8 分。今天新开了一家火锅店，你从没吃过，可能 10 分也可能 3 分。今晚吃哪个？

- 选面馆 = **利用（Exploitation）**：用已知的最优选择，稳；
- 选火锅 = **探索（Exploration）**：承担风险，但可能发现更好的。

只利用不探索，会困在局部最优（也许全城最好吃的餐厅你一辈子没试过）；只探索不利用，就像个永远在乱撞的无头苍蝇，学不到东西。**这个平衡贯穿所有强化学习算法。**

### 6.2 ε-greedy：留一点点"好奇心"

最简单也最常用的平衡方法叫 **ε-greedy（epsilon 贪心）**：

- 以 `ε` 的概率（比如 20%）**随机选动作**（探索）；
- 以 `1−ε` 的概率（80%）**选当前 Q 值最高的动作**（利用）。

代码只有两行：

```python
def choose_action(state):
    if random.random() < epsilon:
        return random.randrange(4)   # 探索：随机走
    return max(range(4), key=lambda a: get_q(state, a))  # 利用：选最优
```

### 6.3 ε 衰减：年轻时多闯荡，年老后守成

训练初期 Q 表全是瞎的，应该多探索；训练后期 Q 表已经很准了，就该少折腾。所以我们让 ε 随回合数衰减：

```
epsilon = max(0.05, epsilon × 0.99)   # 每回合乘以 0.99，最低保留 5%
```

ε 从 1.0（完全随机）一路降到 0.05（95% 按最优策略走）。这和人的成长过程一模一样。

## 七、Q-Learning 完整算法（本篇重头戏）

### 7.1 更新公式

真实世界里，Q 值不可能一次算准（我们对"下一站价值"的估计本身也是猜的）。所以采用**渐进修正**的方式，像考试后订正错题一样，每走一步就把 Q 值往"更合理"的方向挪一点：

```
目标值 target = r + γ × max Q(s', a')       # 这一步"理应"得到的长期分数
误差     error = target − Q(s, a)           # 目标和当前估计的差距
新 Q 值        = Q(s, a) + α × error        # 朝着目标挪一小步
```

合并成一条，就是 Q-Learning 的标准更新公式：

```
Q(s, a) ← Q(s, a) + α × [ r + γ × max Q(s', a') − Q(s, a) ]
```

其中 `α`（alpha，学习率）控制每次挪多大：

- α 太大（接近 1）：步子大，容易在正确值附近反复横跳、不稳定；
- α 太小（接近 0）：步子小，学习非常慢；
- 常取 0.1。

### 7.2 手算一次更新，彻底搞懂

假设现在 Q 表里 `Q(格子A, 向右) = 0`，小人在 A 格向右走了一步：

- 立刻拿到奖励 `r = −0.01`（普通移动）；
- 来到格子 B，B 格四个动作中最高的 Q 值是 `0.5`；
- 取 α = 0.1，γ = 0.9。

代入公式：

```
target = −0.01 + 0.9 × 0.5 = 0.44
error  = 0.44 − 0 = 0.44
Q(格子A, 向右) = 0 + 0.1 × 0.44 = 0.044
```

看，这个动作的 Q 值从 0 变成了 0.044——因为它通向一个"未来还不错"的格子，所以它的价值上升了一点点。**成千上万次这样的微调累积起来，整张 Q 表就准确了。**

### 7.3 算法总流程

{% mermaid %}
flowchart TD
    Start(["新回合开始，重置状态 s"]) --> Decide{"随机数小于 ε ？"}
    Decide -->|"是：探索"| Rand["随机选一个动作 a"]
    Decide -->|"否：利用"| Greedy["选 Q 值最大的动作 a"]
    Rand --> Act["执行动作，环境给出奖励 r 和新状态 s'"]
    Greedy --> Act
    Act --> Update["按公式更新 Q(s, a)"]
    Update --> Check{"s' 是终点（金币/陷阱）？"}
    Check -->|"否"| Decide
    Check -->|"是"| Done(["本回合结束，衰减 ε，开始下一回合"])
{% endmermaid %}

### 7.4 为什么叫"离线学习"？

Q-Learning 有个细节：它在更新时，假设下一站一定会选最优动作（`max Q(s', a')`），**哪怕你实际走的是随机探索的动作**。也就是说，它嘴上跟着 ε-greedy 乱走，心里却在偷偷学习"最优情况下该怎么走"。这种"行为和学习目标分离"的特点，术语叫**离轨策略（off-policy）**，了解即可，不影响写代码。

## 八、Python 完整代码（零依赖，可直接运行）

下面是完整实现，**只用到 Python 标准库，不需要 pip 安装任何东西**。建议复制保存为 `q_learning_demo.py`，直接 `python q_learning_demo.py` 运行。

```python
# -*- coding: utf-8 -*-
# Q-Learning 走迷宫：纯 Python 标准库实现，无需安装任何依赖
import random

# ---------- 1. 环境：4x4 网格世界 ----------
# (0,0) 是起点 S，(3,3) 是金币 G(+1)，(2,2) 是陷阱 X(-1)
# 每走一步奖励 -0.01（鼓励快点到达）
ROWS, COLS = 4, 4
ACTIONS = [(-1, 0), (1, 0), (0, -1), (0, 1)]  # 上、下、左、右
ACTION_NAMES = ['↑', '↓', '←', '→']
GOAL = (3, 3)
TRAP = (2, 2)


def step(state, action):
    """环境转移：输入当前状态和动作，返回(新状态, 奖励, 是否结束)"""
    r, c = state
    dr, dc = ACTIONS[action]
    nr, nc = r + dr, c + dc
    # 撞墙：原地不动
    nr = max(0, min(ROWS - 1, nr))
    nc = max(0, min(COLS - 1, nc))
    next_state = (nr, nc)
    if next_state == GOAL:
        return next_state, 1.0, True
    if next_state == TRAP:
        return next_state, -1.0, True
    return next_state, -0.01, False


# ---------- 2. Q 表 ----------
Q = {}  # Q[(状态, 动作)] = 这个动作未来预期能拿到的总分


def get_q(state, action):
    return Q.get((state, action), 0.0)


# ---------- 3. 超参数 ----------
alpha = 0.1         # 学习率
gamma = 0.9         # 折扣因子
epsilon = 1.0       # 探索概率（开局完全随机，随后逐渐衰减）
epsilon_min = 0.05  # 探索概率下限
decay = 0.99        # 每回合探索概率乘以该系数
episodes = 500      # 训练回合数

random.seed(0)


# ---------- 4. ε-greedy 选动作 ----------
def choose_action(state):
    if random.random() < epsilon:
        return random.randrange(4)  # 探索：随机走
    return max(range(4), key=lambda a: get_q(state, a))  # 利用：选最优


# ---------- 5. 训练 ----------
for ep in range(episodes):
    state = (0, 0)
    done = False
    total_reward = 0.0
    steps = 0
    while not done:
        action = choose_action(state)
        next_state, reward, done = step(state, action)
        # Q-Learning 更新公式
        best_next = max(get_q(next_state, a) for a in range(4))
        old_q = get_q(state, action)
        target = reward if done else reward + gamma * best_next
        Q[(state, action)] = old_q + alpha * (target - old_q)
        state = next_state
        total_reward += reward
        steps += 1
    epsilon = max(epsilon_min, epsilon * decay)  # 衰减探索概率
    if (ep + 1) % 50 == 0:
        print(f"第 {ep+1:3d} 回合：总奖励 {total_reward:6.2f}，步数 {steps}，探索概率 {epsilon:.2f}")

# ---------- 6. 展示学到的最优策略 ----------
print("\n学到的最优策略（每个格子上的箭头表示该往哪走）：")
for r in range(ROWS):
    row_str = ''
    for c in range(COLS):
        if (r, c) == GOAL:
            row_str += '  G '
        elif (r, c) == TRAP:
            row_str += '  X '
        else:
            a = max(range(4), key=lambda x: get_q((r, c), x))
            mark = 'S' if (r, c) == (0, 0) else ' '
            row_str += f' {mark}{ACTION_NAMES[a]}'
    print(row_str)
```

代码分为六个部分，和前面的概念一一对应：

1. **环境定义**：地图、动作、`step()` 函数（输入状态和动作，返回新状态、奖励、是否结束）；
2. **Q 表**：用一个字典实现，键是 `(状态, 动作)`，值是 Q 值，默认 0；
3. **超参数**：α、γ、ε、训练回合数；
4. **选动作**：ε-greedy；
5. **训练循环**：每个回合不断"选动作 → 走一步 → 更新 Q 表"；
6. **结果展示**：训练结束后，把每个格子的最优动作（箭头）打印出来。

这张表就是"学习的痕迹"，可以清晰看到三个阶段：

从 12 步到 6 步，**没有人教过它路怎么走，这就是它自己"试"出来的智能。**

### 9.2 学到的最优策略

```
 S↓  ↓  →  ↓
  ↓  →  →  ↓
  →  ↓  X   ↓
  →  →  →  G
```

从起点 S 沿箭头走：`S ↓ → → ↓ → → G`，正好 6 步，而且**完美绕开了 (2,2) 的陷阱**。你可以自己验证每个格子的箭头，全部指向通往金币的合理方向。

### 9.3 为什么后期还偶尔翻车？

注意第 300、500 回合偶尔出现 7、8 步。那是因为我们保留了 5% 的探索下限（ε_min = 0.05），即"学成之后仍有 5% 的概率故意乱走"。如果想让它考试时满分发挥，评估时把 ε 设为 0、完全按 Q 表行动即可。训练时保留探索，是为了让它持续发现新可能。

## 十、从 Q-Learning 到 DQN：状态太多怎么办？

### 10.1 Q 表的局限

4×4 迷宫只有 16 个状态，Q 表轻松装下。但想想真实任务：

- 下围棋：棋盘状态数量是天文数字（约 10^170）；
- 玩 Atari 游戏：画面是 210×160 的像素，状态几乎无穷；
- 自动驾驶：路况、车速、行人组合无穷无尽。

不可能为每个状态存一行 Q 表。怎么办？

### 10.2 DQN：用神经网络代替 Q 表

2013 年 DeepMind 提出的 **DQN（Deep Q-Network）** 思路是：既然 Q 表本质是一个"状态 → 各动作 Q 值"的函数，那用一个**神经网络**来拟合这个函数不就行了？

- 输入：当前状态（比如游戏画面的像素）；
- 输出：每个动作的 Q 值；
- 训练目标：仍然是 Q-Learning 的贝尔曼更新公式。

DQN 配合两个关键技巧（经验回放、目标网络）稳定训练，在 2015 年做到了在 49 款 Atari 游戏上达到人类水平，直接引爆了这一轮深度强化学习的热潮。

### 10.3 强化学习家族地图

最后给你一张"认路图"，知道 Q-Learning 所处的位置即可：

| 流派 | 核心思想 | 代表算法 |
|---|---|---|
| **基于价值** | 学 Q 值，间接得到策略 | Q-Learning、DQN 系列 |
| **基于策略** | 直接优化策略本身 | Policy Gradient、REINFORCE |
| **演员-评论家** | 价值网络 + 策略网络结合 | A2C、PPO、SAC |
| **基于模型** | 先学环境规律，再规划 | AlphaGo、AlphaZero、MuZero |

## 十一、关键超参数速查表

调参是强化学习的日常，这张表可以收藏：

| 超参数 | 符号 | 作用 | 调大的影响 | 常用取值 |
|---|---|---|---|---|
| 学习率 | α | 每次更新 Q 值的步长 | 学得快但易震荡 | 0.01 ~ 0.5 |
| 折扣因子 | γ | 对未来奖励的重视程度 | 更有远见，但可能难收敛 | 0.9 ~ 0.99 |
| 探索概率 | ε | 随机探索的概率 | 探索充分但短期表现差 | 0.1 ~ 0.2（含衰减） |
| 探索衰减 | decay | ε 每回合的衰减速度 | 衰减快，过早固化 | 0.99 ~ 0.999 |
| 训练回合数 | episodes | 训练总量 | 更多但边际递减 | 视任务而定 |

## 十二、小白常见疑问

**Q1：奖励函数是谁设计的？**
是人设计的，这也是强化学习最关键的工程问题。奖励设计得好，智能体学得又快又好；设计得歪，它会"学坏"——比如你让扫地机器人"避免碰撞"，它可能学会倒退着走（因为倒退时碰撞传感器不响）。这种钻奖励空子的现象叫 **奖励黑客（Reward Hacking）**。

**Q2：训练过程中到底在"训练"什么？**
Q-Learning 训练的是一张 Q 表；DQN 训练的是神经网络的参数。本质都是在让"打分系统"越来越准确。

**Q3：怎么判断训练好了？**
画出每回合的"总奖励 / 步数"随训练回合数变化的曲线（学习曲线）。当曲线从低位**稳定上升并收敛到一个平台期**（像本文从 12 步收敛到 6 步），就说明学得差不多了。你可以把代码里的 `total_reward` 收集起来用 matplotlib 画出来。

**Q4：强化学习和深度学习是什么关系？**
二者是交叉关系。强化学习是"学习范式"（靠试错和奖励），深度学习是"工具"（神经网络）。Q-Learning 不用深度学习；DQN 则是两者结合（深度强化学习）。

**Q5：为什么我的智能体学不出来？**
新手最常见三个原因：奖励设计不合理（比如走路惩罚过大导致它干脆不动）、ε 衰减太快（没探索够就固化了）、训练回合数太少。把这三个旋钮逐一排查，多数问题都能解决。

## 十三、总结

回顾一下，强化学习的完整过程其实就一句话：

> **智能体在环境中观察状态、选择动作、接收奖励，用 Q-Learning 公式不断修正对"每个选择长期价值"的估计，在 ε-greedy 的探索与利用之间反复训练，最终收敛出一条拿到最多奖励的最优策略。**

把核心闭环记住：

```
观察状态 → 选择动作 → 环境反馈(新状态, 奖励) → 更新 Q 值 → 重复
```

动手建议：

1. 把代码跑起来，亲手改改奖励（比如把走路惩罚改成 0，或把陷阱改成 −10），观察策略变化；
2. 把地图扩大到 6×6、多加几个陷阱，看需要多少回合才能收敛；
3. 尝试画出学习曲线；
4. 之后再去学 DQN，你会发现它只是把"Q 表"换成了"神经网络"，核心骨架和本文完全一样。

强化学习的门槛不在公式，而在建立"智能体—环境—奖励"的思维方式。当你能看着一个系统说出"它的状态是什么、动作是什么、奖励是什么、策略是什么"时，你就已经入门了。
